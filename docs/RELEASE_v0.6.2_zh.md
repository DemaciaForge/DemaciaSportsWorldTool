# v0.6.2 — 抓包契约核验与提交结果修正

本版本包含本地尚未发布的协议、设备和分段改进，以及基于 Android 7.4.0 历史抓包完成的离线核验修正。

## 本次修正

- OBS 补齐 `extension_json`，固定 11 个顶层字段和 27 个轨迹点字段的脱敏契约。
- 10 秒窗口使用累计步数边界取整后相减，消除逐窗取整引起的累计步数误差。
- 上传与历史回读统一使用 UTC+8 小时桶，非法时间明确报错。
- 详情获取状态与服务端达标判定分开处理；缺失 `complete` / `isCheat` 显示未知。
- GUI / CLI 显示实际 OBS 上传数量，移除固定 `/2`；COS 日志不再回显签名查询串及可能含签名的错误正文。
- 新增只依赖 Python 标准库的离线 HAR / OBS 审计工具、输入一致性检查及 CI 回归。

## 一并发布的已有改进

- 设备字段、定位速度和采集时间轴的兼容修正。
- 卡路里、平均功率及 30 秒分段数据的口径修正；OBS 使用日期式单键。
- 单条详情首选 `v70320` 接口，并保留旧接口的有条件回退。
- 本地 GeeGuard token 处理及相关协议行为说明。

## CLI 行为变化

`run` 返回 `0` 要求 OBS 全部上传完成，且详情明确达标、无异常。
返回 `2` 表示记录已经保存，但上传或业务判定未完成；应查询该记录，**不要据此自动重复提交**。
`run --dry-run` 的 `0` 仍只表示本地检查通过。
